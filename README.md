# luisgilmartin.com

Portfolio de Luis Gil Martín. Web estática (HTML, CSS y JS sin compilación) publicada con Cloudflare Pages.

- `index.html` · home
- `trabajos.html`, `servicios.html`, `sobre-mi.html`, `legal.html`
- `proyecto-*.html` · páginas de cada proyecto (`proyecto.html` = Martin Miller's Gin)
- `img/` · imágenes y vídeos
- `fonts/` · tipografías autoalojadas (Fontsource, licencia SIL OFL)

Cloudflare Pages: sin comando de build, directorio de salida `/`.
